# RadioBlock (Spigot 26.2 + Simple Voice Chat)

## Сборка (один раз)
Нужны JDK 25 (или тот, на котором работает ваш сервер) и Maven.
    mvn clean package
Готовый файл: target/RadioBlock-1.0.0.jar -> в папку plugins вместе с Simple Voice Chat (bukkit 2.6.20+).

Нет JDK/Maven? Залейте папку в пустой репозиторий на GitHub - вкладка Actions -> Build -> скачайте артефакт RadioBlock.

Если сборка ругается на версию классов - поменяйте в pom.xml <maven.compiler.release> на 21.

## Как пользоваться
1. Рецепт (или /radio give):   _I_ / RCR / _N_   (I - железо, R - редстоун, C - медный блок, N - нотный блок)
2. Поставьте рацию, сверху - громоотвод (антенна).
3. Подайте редстоун-сигнал сбоку/снизу: сила сигнала = номер волны (13 -> волна 13). Без сигнала рация молчит.
4. ПКМ пустой рукой - переключение ПРИЁМ / ПЕРЕДАЧА. Shift+ПКМ - только статус.
5. Говорите в микрофон рядом с рацией в режиме ПЕРЕДАЧА (до 3 блоков) - голос слышен у всех рации в режиме ПРИЁМ на той же волне (звук идёт из блока, радиус 12).
Настройки - plugins/RadioBlock/config.yml.
